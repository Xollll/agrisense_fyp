## 🎓 One Minute System Overview

```
YOLO Detection
    ↓
    Detects multiple diseases + healthy
    ↓
AgriSense App
    ├─ Store ALL in currentDetections[]
    ├─ Filter "healthy" for display
    ├─ Show disease cards in UI
    ├─ User taps "Ask AI for Tips"
    ├─ App checks cache first
    │  ├─ Hit? → Instant display (< 10ms)
    │  └─ Miss? → Call API (1-3 sec)
    │           ├─ Filter "healthy"
    │           ├─ Deduplicate
    │           ├─ Send all to Gemini
    │           └─ Get ONE recommendation
    ├─ Cache result
    └─ Display recommendation
```
