                         ANIMATION IMPLEMENTATION

    Code Structure:

    ModernAnimatedAppBar (StatefulWidget)
    │
    └─ _ModernAnimatedAppBarState
       │
       ├─ AnimationController
       │  └─ Duration: 500ms
       │
       ├─ Animation<double>
       │  └─ Range: 0.0 → 1.0
       │  └─ Curve: easeInOut
       │
       ├─ initState()
       │  ├─ Create AnimationController
       │  ├─ Create Animation
       │  └─ Call _animationController.forward()
       │
       ├─ dispose()
       │  └─ _animationController.dispose()
       │
       └─ build()
          └─ FadeTransition(
               opacity: _fadeAnimation,
               child: Container(...)
             )
