## Animation Mathematics

### V2 Particle Fade
```
opacity = (1 - waveProgress) * 0.9
Effect: Linear fade-out (uniform)
Feeling: Abrupt
```

### V3 Particle Fade
```
opacity = (1 - pow(waveProgress, 0.8)) * 1.0
Effect: Exponential fade (smooth curve)
Feeling: Natural, organic, premium
```

**Math Result**: `pow(0.8)` creates a curve that keeps particles visible longer, then fades smoothly. More natural-looking!
