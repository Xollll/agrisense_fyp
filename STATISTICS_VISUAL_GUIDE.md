## 🎯 Visual Hierarchy

### Typography Sizes
```
Level 1 (Headlines)
- Status: 28pt (bold) - Most prominent
- Section titles: 20pt (bold)

Level 2 (Subheadings)
- Metrics: 16pt (medium weight)
- Card titles: 14pt (bold)

Level 3 (Body Text)
- Main content: 14pt (regular)
- Descriptions: 14pt (regular)

Level 4 (Small Text)
- Labels: 12pt
- Dates/timestamps: 12pt
- Captions: 10pt
```

### Color Hierarchy
```
Level 1: Status Color (Green/Orange/Red)
↳ Used for: Status badge, progress bar, main headline

Level 2: Threat Colors (Red/Orange/Yellow/Green)
↳ Used for: Disease threat indicators

Level 3: Accent Color (Blue)
↳ Used for: Icons, information elements

Level 4: Neutral (Grey)
↳ Used for: Body text, dividers, secondary info
```

## 📱 Responsive Breakpoints

### Mobile (< 600px)
```
- Full width cards minus 16px padding
- Single column layout
- Stacked metrics
- Readable text at 14pt+
```

### Tablet (600-900px)
```
- Slightly wider cards
- Single column (mostly)
- Expanded spacing
```

### Desktop (> 900px)
```
- Max width container (max 1200px)
- Centered on screen
- Horizontal layout where applicable
```

## 🎬 Animation & Transitions

### Page Load
```
- Cards fade in from bottom
- Status bar animates score from 0 to final value
- Progress bars animate fill
- Slight delay between sections (50-100ms)
```

### User Interactions
```
- Button press: Scale 0.98
- Filter chip tap: Color transition (200ms)
- Pull-to-refresh: Standard iOS/Material style
- Time filter: Smooth fade transition
```
