## 🔑 Key Concepts Explained

### Neural Network Icon
The icon shows 5 nodes arranged in a circle around a pulsing white center. The nodes:
- Rotate continuously and with menu animations
- Have individual glow halos
- Display color gradients (cyan → purple)
- Connect with animated lines
- Have particles moving along connections

**Reference**: FLOATING_BUTTON_ENHANCED_ICON.md (Icon Animation Components section)

### Multi-Layer Glow System
Four layers of shadows create depth:
1. **Cyan outer** (60% opacity, 35px blur) - Neon effect
2. **Purple middle** (40% opacity, 25px blur) - Color harmony
3. **Blue inner** (30% opacity, 15px blur) - Cohesion
4. **Deep shadow** (25% opacity, 12px offset) - Grounding

**Reference**: FLOATING_BUTTON_ENHANCED_ICON.md (Glow Effects section)

### Animation Controllers
Three controllers synchronized for smooth effects:
- `_menuController` (500ms) - Menu open/close
- `_pulseController` (1500ms infinite) - Breathing effect
- `_bounceController` (900ms infinite) - Vertical bob

**Reference**: FLOATING_BUTTON_VISUAL_ARCHITECTURE.md (Animation Timeline section)
