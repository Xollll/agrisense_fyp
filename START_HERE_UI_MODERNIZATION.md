## 🎯 HOW TO USE

### Opening Navigation Drawer
```
Tap ☰ (hamburger icon) in top-left corner
OR
Swipe from left edge of screen
```

### Navigating Between Pages
```
1. Open drawer
2. Tap your page
3. Drawer closes
4. New page displays
```

### Refreshing Data
```
On Statistics or History page:
1. Swipe DOWN with finger
2. Circular loader appears
3. Release finger
4. Data refreshes automatically
```
